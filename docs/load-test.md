# 부하 테스트 기준

부하 테스트 문서의 진입점이다. Gatling 소스와 실행 옵션의 원본은 형제 저장소
`../gatling-test`에 있다.

## 목적

로컬 환경에서 예매 오픈 순간의 핵심 위험을 재현한다.

- 대기열 진입 처리량
- 대기열 토큰 발급과 상태 조회 흐름
- 티켓 서버 단독 좌석·주문 처리량
- 같은 좌석 order/hold 경합

**운영 환경에는 직접 부하 테스트를 실행하지 않는다.** 운영과 가까운 처리량은 별도 스테이징
환경에서 같은 시나리오를 재사용해 확인한다.

## 어디를 보나

| 알아야 하는 것 | 원본 |
| --- | --- |
| 실행 전 전제, 시나리오 선택, 용량 산정 순서, 결과 판정, 연속 실행 격리 | **`/loadtest` 스킬** |
| 정확한 명령과 옵션, 완료 기준 | [load-test/ticket-open-local.md](load-test/ticket-open-local.md) |
| 관측 지표와 PromQL | [operations.md의 Core 용량 관측](operations.md#core-용량-관측) |
| Gatling 시나리오 구현과 분산 실행 | `../gatling-test/README.md` |

결과 파일은 git 추적 대상이 아니고 경로가 260자를 넘기 쉽다. 지우거나 옮기기 전에 `tar`로
백업하고, 사용자 확인 없이 정리하지 않는다. 상세는 `/loadtest` 스킬을 본다.
