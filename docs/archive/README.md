# 설계 기록 보관소

여기 있는 문서는 **이미 반영되었거나 폐기된 계획과 설계다. 현행 기준이 아니다.**

에이전트는 **명시적으로 요청받지 않는 한 이 디렉터리를 읽지 않는다.** 검색 결과에 걸리더라도
현재 구조의 근거로 인용하지 않는다. 여기 적힌 모듈 이름, 클래스 이름, 명령이 지금도 유효하다고
가정하지 않는다.

## 지금 기준은 어디에 있나

| 알고 싶은 것 | 현행 원본 |
| --- | --- |
| 모듈 경계, 코드 배치, 의존 방향 | `docs/architecture.md` |
| 왜 그렇게 결정했는지 | `docs/adr/` |
| 도메인 용어 | `CONTEXT.md` |
| 작업 규칙 | `AGENTS.md` |
| 커밋·검증 절차 | `/commit-pr`, `/verify` 스킬 |

## 진행 중인 설계는 여기 없다

아직 반영되지 않은 설계는 `docs/superpowers/`에 있다. 그쪽은 현행 논의 대상이다.

## 언제 읽나

- "이 구조를 왜 이렇게 바꿨더라"를 되짚을 때
- 같은 문제를 다시 만나 과거의 판단 근거를 확인할 때
- 폐기된 대안을 다시 제안하기 전에 이미 검토됐는지 볼 때

어느 경우든 **현재 코드로 먼저 확인하고** 여기는 배경으로만 쓴다.
