# 트리아지 라벨

스킬은 트리아지를 다섯 개의 표준 역할로 이야기한다. 이 표는 그 역할을 이 저장소 이슈 트래커에서
실제로 쓰는 라벨 문자열에 대응시킨다. 이 저장소는 기본 이름을 그대로 쓴다.

| 스킬이 말하는 라벨 | 우리 트래커의 라벨 | 의미 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 아직 판단하지 않은 이슈. 관리자가 평가해야 한다 |
| `needs-info` | `needs-info` | 보고자에게 추가 정보를 기다리는 중 |
| `ready-for-agent` | `ready-for-agent` | 스펙이 충분해 에이전트에게 맡길 수 있다 |
| `ready-for-human` | `ready-for-human` | 사람이 직접 구현해야 한다 |
| `wontfix` | `wontfix` | 처리하지 않는다 |

스킬이 역할 이름으로 말하면(예: "AFK 준비 라벨을 붙여라") 이 표의 오른쪽 문자열을 쓴다.

라벨이 아직 저장소에 없으면 `gh label create <이름>`으로 만든다. 다른 이름을 쓰기로 바꾸면
오른쪽 열만 고친다. 왼쪽 열은 스킬 쪽 어휘이므로 바꾸지 않는다.
